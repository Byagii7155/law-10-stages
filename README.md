# Эрүүгийн хэрэг хянан шийдвэрлэх тухай хууль · Өмгөөлөгчийн оролцооны лавлах

**Шууд үзэх холбоос:** https://byagii7155.github.io/law-10-stages/

## Төслийн зорилго
Эрүүгийн хэрэг хянан шийдвэрлэх ажиллагааны үе шатуудын дараалал болон үе шат бүрд өмгөөлөгчийн оролцоо, эрх, хүсэлт, гомдол, ажиллагааны зохицуулалтыг нэг дороос хурдан, ойлгомжтой харах боломжийг оюутнууд болон сонирхогчдод олгох зорилготой вэб лавлах юм.

## Хэнд зориулагдсан ба ямар асуудал шийдвэрлэдэг вэ?
* **Хэнд зориулагдсан:** Эрх зүйн сургуулийн оюутнууд, өмгөөлөгчид, сургалт болон лавлахын зорилгоор ашиглах сонирхолтой хүмүүс.
* **Шийдвэрлэх асуудал:** Хуулийн үе шат болон өмгөөлөгчийн оролцооны талаарх мэдээллийг нэг цэгт эмх цэгцтэй, хайлт болон шүүлтүүртэйгээр харуулж, суралцах болон лавлах хугацааг хэмнэнэ.

## Худалдан авах / Хамтран ажиллах
* **Нээлттэй үзүүлэн (GitHub Pages):** Дээрх шууд холбоосоор ерөнхий лавлах болон үе шатуудын бүтцийг танилцуулга, сургалтын зорилгоор үзэх боломжтой.
* **Бүрэн багц / Нэмэлт материал / Захиалга:** Сонгосон сэдэв, гарын авлага, бэлэн багц материал эсвэл хамтран ажиллах саналтай бол албан ёсны холбоо барих сувгаар шууд холбогдож нөхцөл, хүргэлтийн хэлбэрийг тохиролцоно.
* **Зохиогчийн эрх:** Энэхүү бүтээлийн эх код, бүтэц болон агуулгыг зохиогчийн зөвшөөрөлгүйгээр хуулбарлах, дахин борлуулах, түгээхийг хориглоно.

## Санамж ба эрх зүйн мэдээлэл
Энэхүү лавлах нь мэдээлэл, сургалтын зорилготой бөгөөд хууль зүйн дүгнэлт болохгүй.
